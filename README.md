# Laws of UI — Agent Skill

A portable Agent Skill for auditing existing interfaces and planning new pages. It turns the Laws of UI into contextual review prompts, with separate workflows for observed interfaces, new designs, and accessibility checks.

## Install

```sh
npx skills add 1arley/laws-of-ui-skill --skill laws-of-ui
```

The skill routes between existing-page audits, new-page planning, and redesigns. Its primary design reference is [Laws of UI](https://uilaws.com/); accessibility claims use the normative [WCAG 2.2](https://www.w3.org/TR/WCAG22/) standard and W3C WAI guidance.

This public GitHub repository is the install source. The [skills.sh FAQ](https://www.skills.sh/docs/faq) says skills enter its leaderboard automatically through CLI installs, so ranking follows genuine installs rather than a manual submission.
